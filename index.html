Simple workflow
Three steps
01 — SELECT
Choose your folder
Select the folder containing your audio files and grant read/write access when the browser asks.
02 — CONVERT
Run the batch
Each file is decoded, resampled and encoded one at a time. Errors are isolated to the affected file.
03 — TEST
Use the SMP files
Open the generated folder and test a file on your MS3V player before replacing originals.


About
Experimental and transparent.
The MS3V workflow is an experimental compatibility finding derived from working files and validated on a physical player. It is not an official proprietary format specification.
